# structure_grain —— 已撤回的「结构描述子」阶段

这个目录里的 16 个脚本属于本项目的 A3 阶段：造一把能量结构的尺子，
用它当质量代理来指导生成。**这条路已经被推翻，论文里作为撤回条目报告**
（附录 A 第一条 + §4.2「The structural ruler ranked them backwards」）。

保留它们是因为论文的诚实性建立在这份记录之上——读者应当能看到被撤回的东西
长什么样、以及它为什么被撤回。**但目录里的代码不支撑正文的任何主张。**

## 被撤回了什么

- **头条「比基线接近真人 6 倍」**（`headline.py`）：那个量是**两组均值之差**，
  不是距离；只有 4 个样本；而且同一把尺子把消融掉的模型排在第一。
  更正后是 1.4 倍，整条主张撤下。
- **尺子本身作为质量代理**：`struct_metric.py` 的三条验收判据全过、折半也稳，
  但它给出的排序与人的偏好**反向**（有种子 0.93 优于无种子 1.74，
  而人给这两层的模型胜率是 5% 与 42%）。
  三条判据管的是「能否区分有无结构」，与「像不像该材质」是两回事。

## 仍然有效、被正文使用的部分

- `analysis/stability.py` 的折半机制（`struct_metric.py` 通过 `split_half` 调用）。
  §4.2 说尺子「split-half stable」指的就是它，与本目录里已删的那段无关。

## 2026-09-09 的两处修复

`analysis/check_names.py` 扫出这里有两个坏点，都因为没有任何脚本引用本目录、
从而长期无人执行：

1. `face_uniformity.py` 的一个 f-string 里 `\n` 被写成了真换行，**整个文件无法解析**。
   已还原（同类事故见 memory 的「Bash 折叠双反斜杠」）。
2. `headline.py` 末尾的「折半稳定性」块引用了从未赋值的 `mod_halves`，
   **从来没跑起来过**。已删除并在原处说明——补全它会产出一个从未存在过的新数字。

修这两处只是让打包进 supplementary 的代码不至于带着语法错误，
**不改变任何已撤回的结论**。
