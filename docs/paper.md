## 一句话主张

低分辨率像素画纹理生成上，**两条主流自动评测路子都失效，且失效同源**——
低分辨率下不存在唯一正确答案；在有效评测（人）之下，
**平凡基线胜过专门设计的方法**，真正的瓶颈是**采样尺度**而非模型容量。

## 判官在 temperature 0 下是确定性的（影响有效样本量）

两轮同种子重跑，**35 对共同判断全部一致、126 个裁剪决策全部相同**
（我独立核对过，不是照抄无头轮次的结论）。

**后果**：

1. **重跑不构成复现**，只测了 API 可靠性；轮次间差异全部来自调用失败。
2. **有效样本量是不同的（提示词 × 尺寸）对数，不是 API 调用次数**——
   报告 n 时不能把重跑次数算进去。
3. 真正的稳健性检验必须**换随机种子（新渲染）或换判官**。
   **已完成**（种子 99 + `claude-sonnet-4-6`，`crop_robust.json`）：
   主效应 **37/42 = 88%，p=4.4e-7**——比 gemini 更强，主结论稳健。
   但 16/24/32 分层为 88%/92%/85%，ρ=−0.029（n.s.）——
   **分辨率梯度已在两个预注册口径下证伪**（B8/B10），主张撤下；
   失败反而选出了更好的机制（单元惯例失配），见 B10。

这条本身值得写进论文的评测方法一节：
用 VLM 判官时，**同种子重跑给出的"稳定性"是假的**。

## 关于"效应随分辨率递减"的措辞（自我校准）

采样尺度立论**蕴含**这个方向——分辨率越高，不裁也能保住越多结构，
裁剪的作用就越小。run1 给出 ρ=−0.315（p=0.047），
**但稳健性 run（种子99+sonnet）里梯度消失（ρ=−0.029）**——16–32 区间太窄，信号脆弱。

**且该方向没有预注册。** B5 确立机制在先、本研究在后，
可我没有在跑之前把这条预测写下来。
故论文表述为"**与机制一致**"，不写"预测被证实"。
本项目已在事后归因上栽过（A3 全阶段用无意义的准确率做判据），措辞必须准确。

### 稳健性检验结果：主效应稳健，梯度不稳健

换种子（21→99）且换判官（gemini→`claude-sonnet-4-6`）后：

| | gemini / 种子 21 | sonnet / 种子 99 |
| --- | --- | --- |
| **主效应（裁后胜）** | 31/40 = 78% | **37/42 = 88%**（p=4.4e-7） |
| 16 / 24 / 32 各档 | 93% / 80% / 62% | 88% / 92% / 85% |
| **分辨率梯度** | ρ=−0.315（p=0.047） | **ρ=−0.029（p=0.855），消失** |

**主效应对渲染采样与判官都稳健**（两轮都高度显著，方向一致）。
**梯度没有复现。**

**这暴露了预注册设计的一个缺陷**：下面那个五档验证用的是与
"发现梯度"那轮**相同的种子与判官**，即使跑出梯度也不算独立证据。
故补跑独立口径（种子 99 + sonnet，`crop_res5b`）。
**两个口径都出现梯度才算数**；只有原口径出现则判为口径特有，不写进论文主张。

**独立口径结果（2026-09-07，`crop_res5b.json`，210 例，触发 95，有效 62）**：
主效应 56/62 = **90%**（p=3e-11），五档各自全部显著
（16→88%、24→93%、32→83%、48→100%、64→90%）；
但梯度 ρ=**+0.044**（p=0.64），48 档 100% ≥ 16 档 88% → **证伪条件触发**。
两个口径一致：**主效应五档全显著且稳健，梯度不存在**。梯度问题就此关闭。
（sonnet 判官画像与 crop_robust 一致：API 失败仅 1，但正反不一致弃 32——
gemini 反之。两judge的弃样机制不同但主效应结论相同，进一步支撑稳健性。）

### 预注册二：单元惯例说自身的预测（写于运行之前）

B10 把机制从"奈奎斯特越界"修正为"**结构单元惯例失配**"：
SDXL 不论输出尺寸都画约 25 个单元，真人惯例约 4.5，失配约 5.6 倍。

**该说法的直接预测**：若让 SDXL **少画单元**，失配变小，**裁剪的收益应下降**。

**操作**：同一批提示词，加上强调大块的修饰词
（`very few large blocks, macro close-up, minimal detail`），
其余一切不变（种子、判官、正反去偏、双条件门）。

**判据（跑前固定）**：

1. 修饰后渲染图的**主周期应显著变大**（单元数变少）——先验证操作有效；
2. 若单元数确实变少，则**裁剪胜率应低于对照组**；
3. 若单元数变少而裁剪胜率**不降**（差值 <5 个百分点或反向）→ **单元惯例说证伪**，
   机制需再修正，如实报告。

**注意**：这次不预测"显著性"，只预测**方向与幅度差**——
上一次预注册（B8）因为把"显著"写进判据而在小样本上必然难以满足，
这是设计缺陷，不重复。

### 预注册二的执行结果：**操作检查失败，检验无效**（B11）

修饰词未能改变 SDXL 的结构单元数（周期 37.0→37.5 px，p=0.953；
触发率 45%→45%）。胜率差 88%→79%（p=0.255）**不能归因于单元数**。

**判据代码写松了**：判据1 只要求"中位数变大"、未要求显著，
0.5 像素的噪声被判为"操作生效"。已记入 B11。
**判据的措辞与实现必须一起写死。**

下一次改用可验证的杠杆：**降低渲染分辨率**（1024→512→384），
操作检查要求 Mann-Whitney p<0.05 且中位变化 ≥20%。

### 预注册三：渲染分辨率杠杆（写于假设检验运行之前，2026-09-07）

**操作搜索结果**（先于本预注册，不构成假设检验）：

- 提示词杠杆全灭：修饰词（B11 p=0.164/0.953）与三种更强变体
  （`period_probe.py`：neg p=0.383、count p=0.189、corner p=1.0）都不改变单元数。
- **渲染分辨率杠杆通过操作检验**（`render_res_probe.py`，21 提示词，seed 99）：
  以单元数 n_units=size/period 计，384 渲染中位 **32.5→9.3（−71.5%），MW 置换 p=0.0062**
  ——两条判据（p<0.05 且 |Δ中位|≥20%）都满足。512 幅度够（−46.6%）但 p=0.088 不过。
  故假设检验用 **384**。

**单元惯例说的预测**：384 渲染单元数 ~9.3，与真人惯例 4.5 的失配从 ~7 倍缩到 ~2 倍，
故**裁剪胜率应低于 1024 对照组**（`crop_ctrl.json`，同 seed99+sonnet，88%）。

**判据（跑前固定，只预测方向与幅度差，不预测显著性——吸取 B8 教训）**：

1. 操作检验已过（上文，独立于胜率数据）；
2. 384 组裁剪胜率比对照组 **低 ≥5 个百分点** → 支持单元惯例说；
3. 若差 <5 个百分点或反向 → **单元惯例说证伪**，如实报告并停止为它找杠杆。

**口径**：同 42 提示词、seed 99、sonnet 判官、正反去偏、双条件门，
唯一差别 `--render-size 384`。**已知混淆（跑前写明）**：SDXL 低分渲染
本身质量下降，且该下降同时作用于裁/不裁两臂——配对比较内部有效，
但若两臂同时变差导致判官弃样率上升，n 会缩水；此外 384 时触发率可能改变，
触发子集与对照组不完全同构，比较胜率时须一并报告触发率。

**结果（2026-09-07，B13）：预注册三成立。** 384 下裁剪胜率 **17% vs 对照 88%**
（−71.7pp，p=6.3e-9），远超 −5pp 判据；逐档一致（88→11、93→14、85→25）。
混杂如实报告：384 组正反不一致弃样率 60% vs 对照 25%（Fisher p=1.6e-4），
但三种弃样处理（弃用/全算裁赢/全算裁输）下判据均成立。
触发率 45%→48% 基本不变（B12 的"门不触发"事后印象来自 6 个样本，是错的）。
机制证据等级：测量（B9）+ 因果（B13 预注册）+ 排除替代解释（B8/B10）。

**门 v2 回溯分析（2026-09-07，本地轮）**：B13 提出"门应逐图比较单元数与惯例
4.5"。回溯检验不支持：pooled 中 t=22 阈值虽给出 fire 组 80% vs no-fire 组 49%，
但这主要复刻 run 间差异；**run 内**逐图单元数与胜负关系弱且方向不一致
（384 组内赢家中位 7.6 < 输家 17.9，与单元过量说逐图版相反，n=4）。
结论：因果效应确立在**条件层面**（渲染尺寸），不能降格到逐图预测；
门 v2 不实现，缺陷写进限制节。

### 预注册（一）：分辨率梯度（已证伪，见 B8/B10）

**预测**：把输出分辨率扩到 48 与 64 后，裁剪的胜率应**继续下降**。
机制：分辨率越高，不裁也能保住越多结构，裁剪能补的东西越少。

**判据（跑之前定死，不得事后修改）**：

1. 48 档胜率 **< 16 档胜率**；
2. 在 {16, 24, 32, 48, 64} 五档上，胜率与分辨率的 Spearman **ρ < 0 且 p < 0.05**；
3. 若 ρ ≥ 0，或 48/64 的胜率**不低于** 16 档 → **预测证伪**，
   采样尺度立论需要修正，论文中如实报告。

**口径**：同一批 42 个提示词、同一随机种子、同一 VLM 判官、正反两问去偏。
唯一变量是输出分辨率。

**已知限制**：VLM 判官会压缩效应（B6），故各档绝对胜率都是低估；
但**压缩对各档一视同仁**，不影响档间比较——这正是趋势检验比绝对值稳健的原因。

## 审稿人会攻击的三点（以审稿视角自查）

### ① 内在矛盾：我们用自己批判的工具支撑自己的主张 —— **最锋利**

论文第 3.3 节论证 VLM 判官不可用于下结论（压缩效应、抹平分层），
而第 5.2 节裁剪方法的 78–90% **全部来自 VLM 粗筛**。

**必须的处置**：

- 明确写成"**下界**"：B6 实测判官把 87% 压成 62%，故观测到的 78–90%
  是被压缩后的读数，真实效应只会更大——**方向上对我们不利的偏差**，
  因此可用作**存在性**证据，不可用作**幅度**证据。
- **人工盲比因此不是可选项**（`study_crop.html`，39 对）。
  没有它，方法一节就是"用被自己否定的尺子量自己"。
  **这是全文最需要用户完成的一件事。**
- 若截稿前拿不到人工数据，方法贡献必须降级为"粗筛证据 + 机制测量"，
  不能声称已验证。

### ② 单标注者

所有人工结论（A4 72 对、B2 24 对）来自同一人。

**处置**：(a) 明写为限制；(b) 准备**重复标注子集**测标注者内一致性
（至少给出噪声上界）；(c) 不声称跨标注者泛化。

### ③ 胜率是"在门触发的样本上"算的

裁剪研究的提示词偏向有方向性材质，且胜率只在触发对上统计。

**处置**：同时报**无条件视角**——42 提示词全集里门触发约 45–52%，
其余材质方法**不改变任何东西**（不裁即原样）。
故正确表述是"**在适用范围内**胜 78–90%，适用范围覆盖约一半提示词"，
而不是"方法整体胜 78–90%"。

## 风险与诚实说明

- **单标注者**是最大弱点。B1 的作者间一致率是从数据算的（不受此限），
  但 A4/B2 的盲比结论都依赖一个人。
- **4.1 的 n=23、功效低**：真实 65% 时功效仅 21%，
  只能排除"真人显著更好"，不能断言等同。
- **窄领域**：像素画纹理。宽度靠"高熵真值下的评测失效"这一层立论，
  但审稿人可能仍认为窄。
