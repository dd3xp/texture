# 方法

更新于 2026-08-31。取代此前描述低频路线的版本（那条路线已在 M6 被证伪）。

## 一句话

**在离散调色板索引空间生成像素画纹理：全局布局由从数据估计的结构先验给出，
细节由掩码预测模型填充。**

## 为什么是这个形状

不是设计出来的，是被一串排除实验逼出来的。

| 试过 | 结果 | 证据 |
| --- | --- | --- |
| 换架构（transformer / conv / hybrid / 加深） | 几何布局从未出现 | A3–A3c |
| 换采样器（两种顺序 × 16/64/256 步） | 从未出现 | A3d |
| 扩数据 7 倍（32/64 瓦片随机裁剪） | 验证 acc 纹丝不动（0.232） | crop 实验 |
| 加权高掩码率样本 | **前提就是错的**，未实现即排除 | A3d |

**关键判别实验（A3h）**：给模型看砖块的上面 N 行让它补下面——
0 行是噪点，8 行砖缝清晰延续，12 行补得与给定部分对齐。

> **所以是生成问题，不是表示问题。**
> 模型知道砖长什么样，只是在空白网格上建立不起全局结构。

这与掩码率曲线互为印证：模型相对众数基线的优势从 10% 掩码时的 **+0.246**
单调崩到 100% 掩码时的 **+0.032**——而生成恰恰从 100% 掩码开始。

结论：**把全局布局交给先验，把细节交给模型。**

## 三个组件

代码在 `model/structural_prior.py`，全部从**训练数据**估计，无手工规则。

### 0. 缝的档位与"这行是不是缝"（A3v）

缝色不再取整幅图索引的 15 百分位（那是个常数，把 56/66 个材质的缝
画得比真人更暗，砖缝成了近乎黑线），改为**在检出的缝行上实测**。

更重要的是由此得到的一道门：**检出的行必须真的是缝才播种**，判据两条——

1. **置换检验**：这些行比随机选同样多的行显著更暗（p ≤ 0.05）。
   不用幅度阈值（幅度分布单峰连续、无自然分界），
   也不用跨作者一致率（缝行有相位歧义，会把 `default_brick` 68% 一起拦下）。
2. **幅度 ≥ 一个调色板档位**：显著不等于够大，
   `default_diamond_block` p=0.04 但幅度仅 0.033，
   **低于一档在离散调色板里根本画不出来**。

拦下的例子：`mcl_core_gold_ore`（p=0.96，幅度 0.000）、
`farming_straw`（幅度 −0.017，缝比面还亮）。

图上有效（`experiments/seam_vs.png`）：`default_diamond_block` 从
"一片蓝加几个白点"变成显出边框结构，`beds_bed_top2` 出现真人那样的白色区块。
机理是假缝把 16 行里 4 行钉死成同一档位，给了模型一个**错的骨架**。
**先验的害处不在少做，在做错。**

### 1. 周期先验（`learn_prior`）

对每个材质，从它的多个作者版本估计行/列暗度廓线的**自相关主周期与相位**，
在检出的位置放砖缝；竖缝**逐层单独估**（错缝砌法相邻层错开半块，
贯通竖线会把它切成网格）。

覆盖 191 个材质中的 **42%**。得分最高的是 brick / nether_brick /
acacia_wood / junglewood 等——**正是之前一直失败的那一类**。

### 2. 边框先验（`learn_border` + `learn_edges` 取并集）

最外一圈相对内部的标准化亮度差，要求**跨作者方向一致率 ≥80%**
（单个作者画了边框不代表该材质有边框）。

整圈均值有盲点：上下边方向相反时互相抵消。
`carts_cart_side` 视觉上明显有边框，整圈差值却只有 **+0.01 / 一致率 50%**。
所以另加**分边检测**（`learn_edges`），四条边各自判方向与一致性，
把它抓成 top **+1.31/88%**、bottom **−1.37/94%**。

**两者互补而非替代**，用 `add_border_union` 取并集：
`tin_block` 整圈过关（−1.23/84%）能给出完整边框，
拆开后却只有 bottom 单独达标（四条边各自的一致率不如整体），
只用分边反而丢三条边。

| | 覆盖 |
| --- | --- |
| 整圈 | 33 / 191（17%） |
| 分边 | 88 / 191（46%） |
| **并集** | **92 / 191（48%）** |
| **周期或边框（总覆盖）** | **118 / 191（62%）** |

**覆盖率上升不自动等于更好**，所以专门验了过度施加的风险：
取"原本无任何先验、被分边新增"的 21 个材质（每个 3 样本），
加边框后距真人从 **0.1445 降到 0.0703**（p=0.00035）。
新增覆盖是真受益，不是硬塞。

### 3. 错缝先验（`learn_bond`，逐材质选择）

竖缝的**周期是材质属性、相位是作者的自由选择**——
`default_brick` 周期 8 的一致率 89%，相位众数只有 27%，
而同一作者相邻层的相位差 61% 落在半周期上（错缝砌法）。
跨作者平均之所以抹平竖缝，就是因为每人选的全局相位不同。

所以估周期、生成时采一个全局相位、相邻层交替偏移半周期。
候选判据选出 10 个材质，是否启用**逐材质离线量选**
（`bond_select.py`，只用训练瓦片），7 个选用错缝。

竖缝可检出率（40 样本）：`default_brick` 0.08→0.15（真人 0.47）、
`nc_woodwork_plank` 0.07→0.33（0.42）、`vessels_shelf` 0.10→0.23（0.46）。
**统计量涨了但画面还不像砖**，这条边界是收窄不是关闭。

> **⚠ A3s：上面这组数字不能当作 A3q 有效的证据。**
> 检出率用的 `_col_period` 是 lag 3–8 上取自相关最大值，赢者通吃。
> 周期 4 有 4 根缝真峰稳赢，**周期 8 只有 2 根，噪声伪峰就能夺冠**——
> 恰恰在砖块上最不可靠。实测：把缝放对、其余填成匹配边缘分布的随机噪声，
> `default_brick` 检出率只有 0.08，而缝的对比度（1.27 vs 0.90）并不弱。
> A3q 的**机制**部分不受影响（周期/相位/半周期偏移都是直接统计），
> 受影响的是改进幅度。

### 4. 填充（`fill_from_seed`）

随机顺序解掩码，**温度 1.3**。两个参数都是被数据逼出来的：

- **随机顺序**：MaskGIT 的置信度顺序在近均匀分布下会塌成纯色
  （最常见单色占比 0.97–1.00，真人是 0.293），且步数越多越糟。
- **温度 1.3**：种子里大量同色会把模型往"继续同色"上拖，
  砖面用色从 12 掉到 9、面内同色占比 0.224 升到 0.346（p=7e-8）。
  T=1.3 拉回 13 色 / 0.232（真人 13 / 0.209）；T≥1.6 开始破坏结构。

## 当前效果

结构统计（79 个有先验的材质，模型每个 **12** 样本）：

| 组 | 纯结构占比 | 距真人 |
| --- | --- | --- |
| 真人原生 | 0.407 | — |
| 降采样基线 | 0.634 | 0.184 |
| 先验 + 填充 T=1.3 | 0.519 | **0.128** |

比基线接近真人 **1.4 倍**（Wilcoxon p=0.032）。

### ⚠ 此前记录的 6 倍 / 0.035 已撤回：那不是距离

**0.035 = 0.453 − 0.418，是两组的均值之差**，而 method.md 把它
放进了标着"距真人"的列，还拿它和基线的 0.207（=0.625−0.418）比出 6 倍。

组均值之差会让**方向相反的误差互相抵消**：
一半材质偏平、一半偏噪，聚合后接近零，但每个材质都是错的。
它衡量不了"每个材质像不像"，只衡量"整体分布的中心对不对"。

A3o 的原始记录里其实同时给了逐材质中位距离（0.145 → 0.066），
那才是该报的量——**2.2 倍，不是 6 倍**。写进 method.md 时取错了列。

两个口径下重算（12 样本、当前先验）：

| 口径 | 原记录 | 复核 |
| --- | --- | --- |
| 组均值之差（**不该用**） | 0.207 → 0.035，5.9× | 0.227 → 0.112，2.0× |
| **逐材质中位距离** | 0.145 → 0.066，2.2× | 0.184 → **0.128**，**1.4×**，p=0.032 |

新数字自身是稳的——折半两半 0.1289 / 0.1237，
Spearman ρ=+0.972，两半独立显著（p=0.036 / 0.028）。

所以头条有两个独立的毛病，都已修：**取错了统计量**，以及**样本不足**
（后者与 A3q 同源：A3f 定下的"必须多样本"只被用在看图上）。
纪律已落成代码 `analysis/stability.py`，报结果前强制折半检验。

### 而且这个指标没资格裁决结构先验

A3o 自己记过：**"模型无种子"在该指标上距真人 0.016，
比有种子的 T=1.3（0.035）还"好"**——它把**完全没有结构**排第一。
当时写了"不能单独作为判据"，却仍然把它当了头条。

消融也印证：同一材质集、12 样本下换成当前先验（A3p+A3q），
比值不变（1.5×）但 p 从 0.0002 掉到 0.087。
这不构成"新先验有害"的证据——一个把无结构排第一的指标，
在结构先验上的下降读不出方向。
A3p 与 A3q 各自在**它们要修的量**上是正的
（新覆盖材质 0.1445→0.0703 p=0.00035；竖缝检出 0.08→0.15，7/10）。

**所以头条不该是这个数。人工盲比（A4）是唯一裁决者。**
拆解见 `experiments/headline_ablation.txt` 与 A3r。

### 替代指标：结构描述子距离（`struct_metric.py`）

不量像素统计，量**布局描述子**与该材质训练瓦片描述子分布的标准化距离
（行/列周期强度、竖缝命中比例、四边对比度、平坦度，各维按 MAD 归一）。

验收判据**在测之前写死**。107 个有结构材质、每个 12 样本：

| 判据 | 结果 |
| --- | --- |
| 1 真人留出最好 | ✅ 0.76 vs 有种子 0.95 |
| 2 无种子最差 | ✅ 1.74 vs 有种子 0.95 |
| 3 颗粒材质罚硬塞结构 | ✅ **+66.4%，p=7.9e-08** |

折半 ρ=+0.91、两半差 3%，**稳定**。**三条全过。**

**第 2 条正是旧指标搞反的那条**——旧的全局平坦度指标把无种子排第一。

### 第 3 条曾经不通过，原因是聚合方式

第一版跨 9 维取**平均**，硬塞假结构只被罚 0.5%（p=0.283）。
逐维查下来信号一直在——行周期强度 0.94→1.71、平坦度 0.74→**3.40**、
下边 0.98→1.73——但总分是 45、单维最大 **357**：
某些材质某一维 MAD 近零，除下去就炸，
**少数极端维度主导整个分数**，把真实响应埋掉。

**稳健归一化（MAD）之后用非稳健的平均聚合本来就是错的。**
改成跨维取中位，三条全过。
（试过给 MAD 加下限，无效——它同时缩小信号和噪声。）

**这更不足以宣布胜利。** 本项目反复出现指标与人的偏好脱节
（D5 指标赢盲比输、A3 三轮 acc 涨画廊不动）。
**人工盲比（A4）是唯一裁决者**，任务已生成待标注。

## 端到端（项目最初陈述的任务）

`model/generate.py`：**纯色 + 材质名 + 分辨率 → 像素纹理**。

此前所有评估都是"用真人瓦片的调色板复现该瓦片"——**调色板是抄来的**。
真实使用时只有一个纯色，调色板必须从它派生：
按亮度生成 K 档色阶（保持"索引=亮度档位"这一模型学到的约定），
饱和度随明度轻微下降（暗部偏灰是像素画常见处理）。

实测（`experiments/end_to_end.png`，每种 4 样本）：

| 输入 | 检出先验 | 结果 |
| --- | --- | --- |
| `#8b5a2b` + wood | 横缝[3,7,11,15]，0.67 | 横向木板条纹，色阶正确 |
| `#a03a2a` + brick | 横缝[2,6,10,14]，0.70 | 红色砖层，**无竖缝**（已知限制） |
| `#9a9a9a` + stone_brick | 横缝[7,15]，0.48 | **灰色砖块网格，最接近可用** |
| `#d9c48a` + sand | **无先验，0 格种子** | 沙粒质感，正确无结构 |

也支持区域 mask（`--region`），区域外留白，
因此可以直接用于"在给定形状上画纹理"这一原始任务。

## 能力边界（全部实测）

每一行标注**证据强度**，因为本项目多次出现"结论对、支撑它的量不对"。

| 结构类型 | 状态 | 证据 |
| --- | --- | --- |
| 周期结构（砖行、板条） | ✅ 42% 材质 | 强：直接统计，A3i–A3l |
| 跨作者一致的边框 | ✅ 检出可靠 / ⚠ 生成收益待验 | 检出强（直接统计）；**"加了更像真人"原用 `frac_zero` 量的，该指标已被 A3r 否掉，正用新尺子重验（A3w）** |
| 单边不对称的边框 | ✅ 已解决 | 强：`carts_cart_side` top +1.31/88%、bottom −1.37/94%（A3p） |
| 颗粒材质（沙、苔藓） | ⚠ **只有构造性论证** | 弱：检不出周期→种子为空，必然如此；但结构尺子**证不了**它（硬塞假结构只罚 0.5%，p=0.283，A3u） |
| 相位不一致的错缝 | ⚠ **机制查清，改善幅度无有效证据** | 机制强（周期一致 89%、相位 27%、相邻层差半周期 44 对里 27 对，全是直接统计）；**改善幅度已撤回**：竖缝检出率的检测器在周期 8 上赢者通吃（A3s），且真人基准用了真人自己不共享的相位（A3t） |
| 对角线等其他非周期结构 | ❌ 不覆盖 | `tin_block` 拿到边框但没有对角线 |

### 关于"正确不加种子"

这一条曾被写成"比任何单项修复都重要"，理由是先验可以无差别套用、
不会破坏本来就好的那 38%。**这个推论目前没有独立支撑**：
唯一能检验它的结构尺子在第 3 条判据上不通过（A3u）。

构造性论证仍然成立——检不出周期的材质种子确实为空，这是代码保证的。
但"不作为是**对的**"（而不只是"没做事"）没有量化证据。

## 方法论备注

本项目已推翻自己七次。两条教训固化进了流程：

1. **画廊判读必须多样本。** A3f 发现此前所有定性结论都是 n=1，
   而同一检查点不同采样之间的差异**大于**不同检查点之间的差异。
   曾被当作突破的"边框+对角线"是单次采样的运气，8 次重采样无一复现。
2. **指标好看不等于做对了。** 每个定量结论都要配一次看图；
   每次看图都要够张数。
