## 0. 先认清旧模型为什么失败（新架构必须正面解决这些）

仓库里已经有过一个同一家族的模型（`model/model.py`，调色板索引空间上的 MaskGIT
掩码预测）。战绩：**纯模型对朴素降采样 40:60 输**（D6，116 对，p=0.032）；
加手工结构先验后 **17:83 输**（A4）。旧画廊的诊断：**均质材质（沙、苔藓、土）可用，
有几何结构的材质（砖、木板、箱面）出噪点**。对照代码，三个具体缺陷：

| 旧模型 | 后果 | 新架构的对策 |
| --- | --- | --- |
| **绝对位置编码**（`self.pos` 逐格学） | 不平移等变：砖行在每个相位都要单独学，而每个材质约 8 张样本 → 结构学不会 → 噪点 | **环面（toroidal）相对位置** + **循环平移增广**（纹理可平铺，任意循环平移都是合法样本，16×16 上等于 256 倍数据）。可平铺性由构造保证 |
| **封闭词表材质 ID**（`nn.Embedding(521)`） | 任意材质名（任务要求）无法处理；每个 ID 样本太少 | **开放词表语义条件**：冻结的 CLIP 文本编码器（`openai/clip-vit-base-patch32`，服务器离线可用） |
| **小模型、训练 ≤12 分钟** | 容量与训练量都不足 | 正常规模训练（小时级），带验证集选检查点 |

另外一条来自全项目的核心发现：**大模型知道材质长什么样，但不知道像素画家怎么画
（每图 ~25 个结构单元 vs 真人 ~3.2）；小模型能学真人惯例，但 4951 张图学不到开放语义。**
新架构应当**把两者接起来**，而不是二选一。

## 1. 新架构 v1：渲染条件的环面离散扩散（工作名 TRD）

- **表示**：16×16（后续 24/32）的**亮度秩索引**网格——每张瓦片的实际用色按亮度升序
  重编号（`model/tiles_data.py::canonicalise`，已自检：像素级可逆）。结构与配色解耦：
  模型出结构（秩图），配色另由调色板头给出，再移到用户区域的颜色上（任务要求配色跟随区域）。
- **生成过程**：吸收态离散扩散（masked / absorbing-state discrete diffusion），
  余弦掩码日程，采样多步 + classifier-free guidance。**目标是建模分布，不是拟合唯一答案**
  （真人逐格一致率只有 9.8%，逐像素重建目标本身就是错的）。
- **主干**：双向 Transformer，**环面相对位置偏置**（注意力偏置按 (dy mod N, dx mod N) 查表），
  无绝对位置 → 平移等变。
- **条件**：
  1. CLIP 文本嵌入（材质名，开放词表）；
  2. 可选：**大模型渲染的全局嵌入**（SDXL 渲染图的 CLIP/DINOv2 图像嵌入，非像素对齐）——
     把大模型对"这个材质长什么样"的知识蒸进来，而不是降采样它的像素；
  3. 色阶数 k（2–16）。
- **调色板头**：预测 k 个颜色（相对区域颜色的偏移，亮度有序），交付时移到用户颜色上。
- **增广**：循环平移（全部 256 个相位）、水平翻转；各向同性材质可加 90° 旋转（v1 先不加）。
- **数据**：`split=train` 3395 张 16×16（许可干净，见 `docs/dataset.md`）；`val` 291 张调参；
  `test` 1265 张（12 个未见过的包）只用于最终评测。

## 3. 指标（领域通用，不自造）

调研依据（2026-09-11）：
- 图像生成通用：**FID**（Heusel 2017）、**KID**（Bińkowski 2018，小样本更稳）、**CLIP score**
  （图文一致性）。
- 近年推荐用 **DINOv2 特征的 Fréchet 距离（FD-DINOv2）** 替代/补充 Inception-FID
  （Stein et al., NeurIPS 2023 "Exposing flaws of generative model evaluation metrics"）。
- 平铺纹理（Tiled Diffusion, CVPR 2025；TexTile, CVPR 2024）：**FID、LPIPS 多样性、平铺分、图文相似度**。
- 像素化方法（SD-piXL, SIGGRAPH Asia 2024）：**语义相似度、保真度、美学** + 人工感知研究。

本项目采用：

| 指标 | 量什么 | 实现 |
| --- | --- | --- |
| **KID / FID**（Inception） | 与测试集真人瓦片的分布距离 | 自实现（服务器无 scipy/torch-fidelity）；Inception FID 权重本机下载后 scp |
| **FD-DINOv2** | 同上，更新的特征 | `facebook/dinov2-small`（离线可用） |
| **CLIP score** | 与 "pixel art texture of {材质}" 的一致性 | `openai/clip-vit-base-patch32`（离线可用） |
| **LPIPS 多样性** | 同一提示词多个样本之间的平均 LPIPS | 权重本机下载后 scp |
| **平铺性** | 3×3 平铺后接缝处的不连续度（+ TexTile 若能取得权重） | 自实现 |
| **大模型评审** | 两两偏好（用户 API） | 正反两问去偏；先量可解率（含空对照） |

⚠ 16×16 图用 NEAREST 放大到特征网络输入尺寸；真人与生成**同一套预处理**。
⚠ KID/FID 的参照集 = `split=test` 真人瓦片；**绝不拿测试集调参**。
