## Title (working)

**When There Is No Right Answer: Evaluation Failure and a Sampling-Scale Fix
for Low-Resolution Pixel-Art Textures**

## Abstract (draft)

低分辨率像素画纹理生成暴露了生成模型评测的一个盲区：当输出只有 16×16
个离散色格时，同一材质的独立作者逐格一致率仅比配对零假设高 1.2 个百分点
（0.098 vs 0.086，50k+ 作者对）——**不存在唯一正确答案**。我们证明这使
两条主流自动评测路线同时失效：(1) 逐像素指标度量的是边缘分布拟合而非质量
（我们自己的三轮架构迭代中验证准确率持续上升而输出纹丝不动）；(2) VLM 判官
把人工盲比中 87% 的效应压缩到 62%（p=0.14）并抹平分层结构，位置偏好高达
67%。在有效评测（人工盲比）之下，一个平凡的降采样基线以 83:17 击败专门
设计的掩码预测模型，且与真人手绘不可区分（43%，p=0.68）[待 60 对扩样坐实]。
真正的瓶颈不在模型容量而在**采样尺度**：SDXL 无论输出尺寸如何都渲染约 25
个结构单元，而真人惯例是每瓦片约 4.5 个（两个独立来源测得）。按检测到的
结构主周期裁剪即可修复，在四个独立 run（两判官 × 两种子）中裁剪胜率
78–90%（最高 p=3e-11），适用条件（周期检出且各向异性 ≥0.20）由数据导出并
经留出材质验证。我们预注册并**证伪**了纯奈奎斯特解释——若失真全部来自
采样极限，裁剪收益应随分辨率升高而消失，实测 64 像素档仍胜 79–90%——
从而把机制修正为**结构单元惯例失配**，采样越界只是 16 像素下的加重因素。

## 1. Introduction

论证链（每步一段）：

1. 任务：纯色图 + 材质词 → 低分辨率（16/24/32）像素画纹理。看似小任务，
   但它把"参考不唯一"推到极端：离散调色板 + 极少格子，使一致率可精确计算。
2. 事实一（评测失效同源）：作者间逐格一致率几乎等于配对零假设（B1/B7）。
   推论：逐像素损失/指标测不到质量（3.2，A3 实例）；VLM 判官同样失效但
   方式不同——方向可用、幅度与分层不可用（B6）。
3. 事实二（基线强于方法）：在人工盲比下，降采样基线击败专门方法 83:17
   （A4，预注册），且给定合适高分源时与真人不可区分（B2）。
4. 事实三（真瓶颈是尺度惯例）：新材质无高分源时基线弱，不是模型不会画，
   而是 SDXL 的结构单元数（~25/瓦片）与真人惯例（~4.5/瓦片）失配五倍余
   （B5/B9/B10）。按主周期裁剪修复之，四 run 稳健（5.4）。
5. 方法论贡献的一般性：任何"高熵真值"任务（图标、emoji、UI 主题）都会
   遇到同样的评测陷阱；我们给出可精确计算的一致率检验作为诊断工具。

贡献列表（四条）：

- **诊断**：可精确计算的作者间一致率检验，证明本任务无唯一参考（3.1）；
  两条主流自动评测路线在此失效的实证（3.2/3.3）。
- **基线校准**：预注册人工盲比显示平凡基线胜过专门方法（4.2）、
  与真人不可区分（4.1）[待扩样]。
- **机制与修复**：结构单元惯例失配的测量（B9/B10）、按主周期裁剪的准则
  及其由留出验证的适用条件（5.2/5.5）[待盲比]。
- **评测方法论**：VLM 判官在本域的失效画像——67% 位置偏好、效应压缩、
  分层抹平、温度 0 下确定性导致"重跑复现"是假象（B6 + 判官确定性）。

## 3. There Is No Right Answer

- 3.1 作者间一致率 0.098 vs 配对零假设 0.086（50753 作者对）。
  **诚实注**：早期用有偏零假设报告过"低于随机"，B7 撤回；写清配对构造。
- 3.2 推论 + A3 案例：acc 上升、画廊不动。
- 3.3 VLM 判官失效：87%→62%（p=0.14），分层 6%/33% → 37%/42%；
  位置偏好 67% 须正反两问；温度 0 下 35 对共同判定 100% 一致 →
  重跑不是复现，有效 n = 图对数而非调用数。

## 4. A Trivial Baseline Is Enough (When the Source Is Right)

- 4.1 基线 vs 真人：24 对 43%（p=0.68）；功效不足（65% 时 21%），

## 5. The Real Bottleneck: Structural-Unit Convention

- 5.1 失败诊断：五种降采样核在越界样本全败 → 不是核设计问题（B4/B5）。
- 5.2 修复：按主周期裁剪，目标 size/4.5 由 5979 张真人瓦片导出（5.3）。
  VLM 粗筛四 run：78%（gemini/s21）、88%（sonnet/s99）、
  五档口径 83%（gemini）/90%（sonnet，p=3e-11）[人工盲比待标，
  B6 表明 VLM 数字是低估]。
- 5.3 适用条件：周期检出 **且** 各向异性 ≥0.20；命中 70%→90%、
  误检 35%→6%；阈值在手挑材质上定、留出材质复验 93%/16%（5.5/5.6）。
- 5.4 预注册证伪与机制修正（论文最有区分度的一节）：
  - 预注册预测：纯采样解释 ⇒ 裁剪收益随分辨率递减。
  - 两个独立口径均证伪（ρ=−0.137 p=0.277；ρ=+0.044 p=0.64；
    48 档 100% ≥ 16 档 88%）。64 像素档裁剪仍胜 79–90%，
    而此时 47 像素周期已占 2.9 输出像素、高于奈奎斯特。
  - 修正后的机制：SDXL 画 ~25 个结构单元/瓦片，真人惯例 ~4.5
    （B5 瓦片与 B9 高分源两个独立来源一致）；蕴含裁剪因子
    25/4.5≈5.6，与实测 1/4.2–1/5 吻合。奈奎斯特越界只是 16 像素下的
    加重因素。**两种解释被失败的预测分开**：纯奈奎斯特预测梯度、被证伪；
    单元惯例预测无梯度、幸存。若梯度出现，两者将无法区分。
  - 本机制自带未测的可证伪预测：让 SDXL 画更少单元（提示更大块或
    渲染更小图）应使裁剪收益缩小——写进 future work。
- 5.5 真人源为何不需要裁剪（B9）：125 个真人高分源降到 16 后周期占
  4.80 输出像素（仅 12% 越界），SDXL 渲染 0.73–0.95（越界五倍）。
