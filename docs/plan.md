## 为什么做这件事

2026-08-24 撤回了 S1 的证伪判定（见 `premise.md`）。原因：
现有七个特征（颜色数/平坦度/边缘锐度/主周期/连通块密度/连通块大小/游程）
对**肉眼明显的差异失明**——SDXL 源与真人源经同一条流水线产出的结果，
读数几乎一致，视觉上却一个是木板墙、一个只是竖条纹。

**尺子瞎，所有基于它的结论都不可信。** 在造出一把能用的尺子之前，
方法实现、方向选择、论文定位全部无从谈起。

这件事**不依赖方向决定**，三个候选方向（换任务/换角度/换方向）都需要它。

## 步骤

- [ ] **M1 造判别测试集**
      需要一批"人一眼能分好坏、而现有特征分不开"的成对样本，用来当尺子的靶子。
      做法：对 `data/contentdb/pairs.json` 里覆盖度高的材质（≥8 个高分辨率源），
      用同一条 `baselines/downsample_quantize` 尾巴，分别以
      (a) 真人高分辨率纹理 (b) SDXL 生成纹理 为源，产出 16/32/64 三档。
      产出：`experiments/metric/testset/`，以及一份 CSV 记录每对的
      材质、尺寸、两个源、七个旧特征的读数差。
      **验收**：至少 30 对，且旧特征在其上的分离 AUC < 0.65（确认旧尺子确实瞎）。

- [ ] **M2 试候选指标**
      在 M1 的测试集上逐个测，看哪个能把 (a)(b) 分开。候选按成本排序：
      1. 多尺度对比度：把图再降一半，看结构还剩多少（母题粗则存活）
      2. 自相关峰强度（不是峰位置）——板缝这类周期结构会给出强峰
      3. 频谱低频能量占比：粗母题集中在低频，细木纹在高频
      4. 连通块的**尺寸分布形状**（不是均值）：粗母题应有少数大块
      5. 感知嵌入：CLIP / DINO 对 16×16 放大图的特征距离
      **验收**：任一指标在 M1 测试集上 AUC > 0.80 即算找到尺子。
      若全部 < 0.80，如实记录并停下来问，不要硬凑。

- [ ] **M3 用新尺子重测原立论**
      拿 M2 找到的指标，重跑 S1 的实验（真人 16px vs 真人高分辨率降采样，
      392 材质）。这是 S1 做错的那件事，现在用不瞎的尺子重做。
      结论三选一并写清楚证据：立论成立 / 立论证伪 / 仍无法判定。

- [ ] **M4 量化"什么样的高分辨率源经得起降采样"**
      用新尺子测：真人源和 SDXL 源在降采样前的高分辨率图上，
      有什么可测的差别能预测降采样后的好坏。
      这直接指向生成端该优化什么。
