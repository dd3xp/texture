## 背景：为什么改架构

D6 盲比结论：**降采样基线显著击败本模型**（60%，p=0.032，n=116），
且**基线与真人手绘统计上分不出来**（56%，p=0.804）。
D5 的画廊显示模型**在均质材质（沙/苔藓/土）上可用，
在几何结构材质（砖/板条/箱面）上输出噪点**。

数据不是瓶颈：把等效训练数据扩 7 倍（32/64 瓦片随机裁剪），
验证 acc 纹丝不动（0.232 → 0.232），只是过拟合减轻（差距 +0.207 → +0.118）。

**当前假设**：现有架构是纯 transformer 在 256 个 token 上做掩码预测，
**没有任何空间归纳偏置**——它不知道"相邻格子"意味着什么，
位置信息只来自可学习的位置嵌入。砖缝、板条这类布局需要局部性先验。
这与"均质材质可用、几何结构失败"的观察对得上。

## 步骤

- [x] **A1 实现带空间归纳偏置的架构**
      在 `model/` 里加一个可选架构（`--arch conv`），
      与现有 `--arch transformer` 并存以便对照。
      设计：残差卷积块在 16×16 网格上做掩码预测，
      条件（材质 + 调色板）通过 FiLM 注入。
      保留不变的部分：输出仍是调色板索引、掩码预测目标、
      随机顺序解掩码采样（D5 修好的那个）、区域约束机制。
      冒烟测试要覆盖与 transformer 相同的四条承诺。

      **完成（2026-08-29）**：`model/model.py` 里的 `ConvTextureModel`，
      `build_model(arch, ...)` 按名字构建，两种架构**接口完全一致**，
      所以 `training_step` 和 D5 修好的随机顺序采样器都不用改。

      设计：残差 3×3 卷积块 + GroupNorm，条件（材质嵌入 + 调色板均值向量）
      经 MLP 混合后用 **FiLM** 逐通道注入。
      卷积架构没有 token 序列可拼条件，FiLM 比铺成额外通道更省参数。

      **判断（需要负责人定夺，未自行推进）**：问题可能在**训练目标**，
      不在架构。掩码预测训的是"给定上下文补空缺"，acc 涨说明补空缺越来越准；
      但生成时**从全掩码开始**，没有上下文，全局布局要从零建立——
      **这个能力训练目标从未奖励过**。
      这解释了为什么均质材质始终没问题（局部统计够用），
      而几何布局始终立不起来（需要全局一致性）。

      **诊断已被实测证实（2026-08-30）**，不再是推断。
      在验证集上按掩码率逐档测准确率：

      | 掩码率 | 模型准确率 | 众数基线 | 模型优势 |
      | --- | --- | --- | --- |
      | 0.10 | 0.414 | 0.168 | **+0.246** |
      | 0.25 | 0.399 | 0.169 | +0.229 |
      | 0.50 | 0.350 | 0.167 | +0.183 |
      | 0.75 | 0.292 | 0.161 | +0.131 |
      | 0.90 | 0.236 | 0.150 | +0.086 |
      | **1.00** | **0.109** | 0.077 | **+0.032** |

      **模型相对基线的优势随掩码率单调崩塌，从 +0.246 掉到 +0.032（−87%）。**
      而**生成恰恰发生在掩码率 1.0**——模型几乎没有优势的那一端。

      这解释了三轮的全部现象：验证 acc 在 0.25/0.5/0.75 上测
      （**模型擅长的区间**），架构改进都在那里见效；
      画廊质量取决于掩码率 1.0 的能力（**几乎无优势的区间**），所以不动。

      也顺带说明**训练时的掩码率分布有偏**：余弦调度虽然覆盖到 1.0，
      但 1.0 附近的样本占比很小，模型没被充分训练过从零生成。

      可能的方向（都未验证，需要决策）：
      1. 训练时**加权高掩码率样本**，直接奖励从零生成。
         现在有了实测支持：1.0 处优势只有 +0.032，这一端确实没被训练好。
         改动最小，但风险是模型学会"输出一个平均纹理"来降低损失。
      2. 改成**自回归**或**扩散**目标——两者都显式建模联合分布
      3. 承认 16×16 全局布局需要的是**结构先验/程序化生成 + 模型只做细节**

- [x] **A3d 排除采样器与掩码率分布（2026-08-30）**

      **两个候选方向被测掉，都没走到实现就排除了。**

      **一、"加权高掩码率样本"——前提是错的，方案作废。**
      A3c 的 commit 里我断言"余弦调度虽覆盖 1.0 但那一端样本少"。
      实测训练时的掩码率分布：**≥0.9 占 28.7%、≥0.99 占 9.0%**，充足。
      所以掩码率 1.0 处优势只有 +0.032 **不是训练不足**，
      而是从零预测本身接近信息上限（无上下文时最优解就是边缘分布）。
      **没有实现这个修法，直接省掉。**

      **二、"并行解码破坏全局一致性"——采样器也不是瓶颈。**
      随机顺序下把每步只填 1 格（steps=256），解码退化成
      随机顺序自回归，**正确建模联合分布**：

      | 解码步数 | 纯结构占比 | 跳档:相邻 |
      | --- | --- | --- |
      | 16 | 0.367 | 5.00 |
      | 64 | 0.410 | 4.81 |
      | **256（一次一格）** | **0.438** | 5.00 |
      | 真人参照 | **0.438** | 4.24 |

      纯结构占比单调逼近并**精确对齐真人的 0.438**，
      但画廊（`experiments/cmp_s256/gallery.png`）上
      **几何结构一点没动**——tin_block、grass_side、
      carts_cart_side、desert_sandstone_brick 全是噪点。

      **排除链至此完整**：架构（4 种）、采样器（2 顺序 × 3 步数）、
      数据量（7 倍）、训练目标（掩码率分布已核实）——
      几何布局在任何一项上都没出现过。

- [x] **A3h 砖块补全诊断：表示问题还是生成问题（关键）**
      A3g 确认砖块是多样本下唯一稳固的失败点，拿它当靶子做判别实验：
      **给模型看砖块的上面 N 行，让它补下面**。
      若能正确延续 → 模型能表示砖结构，只是从零建立不起来（生成问题）；
      若不能 → 模型根本没学到砖结构（表示问题）。

      **结果（2026-08-30）：是生成问题，不是表示问题。**
      `experiments/brick_inpaint.png`，两种砖材质 × 4 档给定行数 × 3 样本：

      | 给定 | 补全结果 |
      | --- | --- |
      | 0 行（从零生成） | 噪点，无砖行 |
      | 4 行 | 开始出现横向砖缝 |
      | 8 行 | **砖缝清晰延续，出现砖块** |
      | 12 行 | **补全相当好，砖行与给定部分对齐** |

      两种材质、每档 3 样本，趋势一致且单调。

      **模型知道砖是什么样，给够上下文就能正确接下去；
      空白网格上建立不起全局结构。**

      这与掩码率曲线（模型优势从 +0.246 崩到 +0.032）
      **是同一件事的定性与定量两种证据，互相印证**。

      **直接推论**：解法是**给模型一个结构种子**——
      先用程序化方法或另一个小模型定出粗略布局（砖的行列、边框位置），
      再让本模型填细节，因为它在有上下文时表现良好。
      这正是先前列的第 3 个方向（结构先验 + 模型做细节），
      **现在有了直接证据，不再是猜测**。

- [x] **A3i 结构种子：先验定布局 + 模型填细节**
      A3h 证明砖块是生成问题不是表示问题，直接推论是给模型一个结构种子。
      实现：程序化放砖缝（横缝 y=0/y=8，竖缝按行错缝 x=0/x=8），
      其余交给模型填。

      **结果（2026-08-30）：结构种子有效，是 A 阶段第一个可重复的结构性成功。**
      `experiments/brick_seed.png`，**4 种砖材质 × 3 样本**：

      | | 结果 |
      | --- | --- |
      | 无种子 | 杂色噪点，无砖行（与之前一致） |
      | **有种子** | **砖缝网格清晰保持，模型围绕它填充** |

      4 材质 × 3 样本**全部一致**，不是单次运气——
      这是 A3f 教训之后要求的多样本验证。

      **但色调不对。** 种子填的是最暗档（index 0，调色板按亮度排序），
      模型看到大量深色上下文后**把砖面也填暗了**——
      `brick` 那行尤其明显：真人是砖红色，生成接近全黑加零星亮点。
      **结构对了，色调塌了。**

      **修复过程（同日）：先发现位置也是错的，最后用"从数据学先验"一并解决。**

      查"真人在种子位置上的众数档"时发现异常：
      desert 系两个材质是 **14 和 15（接近最亮）**——
      说明我的种子位置落在了**砖面**上而不是砖缝。
      **不只是颜色错，位置也错。**

      直接量真人的砖缝在哪（每材质 25–41 个作者版本）：

      | 材质 | 最暗行的常见位置 | 我硬编码的 |
      | --- | --- | --- |
      | desert_stone_brick / stone_brick | **(6,7,15)** | (0,8) |
      | brick | (2,10,14) / (6,10,14) | (0,8) |

      砖缝在每层**底部**（第 7、15 行）而非顶部，且 `brick` 层高不同。
      **差一行，整个结构就对不上。**
      但同材质不同作者之间位置基本一致 →
      **布局先验可以从训练数据估计，不必手工指定**。

      **最终做法**：对每个材质，从它在**训练集**里的多个作者版本估计
      (a) 哪些行/列经常显著偏暗（砖缝位置），
      (b) 最暗 15% 像素的中位档相对调色板的位置（砖缝档位）。
      用这两个量生成种子，其余交给模型填。

      **结果（`experiments/brick_learned_prior.png`，每材质 3 样本）**：

      | 材质 | 学到的砖缝行 | 结果 |
      | --- | --- | --- |
      | desert_stone_brick | **[7,15]** | **横向砖层清晰，色调正确** |
      | desert_sandstone_brick | **[7,15]** | 同上，明显像砖 |
      | stone_brick | [7,15] | 有横缝和竖向结构，可用 |
      | brick | [2,6,10,14] | **多检出 2 行**，成横条纹不是砖 |

      **4 个里 3 个成立**，且 index 0 造成的发黑问题消失
      （先验估出的砖缝档是 1–2）。
      `brick` 失败是行检测阈值过松（真人只有 2 层，检出 4 行）。

      **结论**：这条链完整了——
      多样本定位靶子（A3g）→ 判别是生成问题（A3h）→ 加种子（A3i）→
      从数据学先验修正位置与色调。
      **先验是学的不是手工的**，因此可推广到其他材质。

- [x] **A3l 错缝砌法：逐层估竖缝，并发现先验的本质限制**
      A3k 遗留问题：贯通竖线把错缝砌法切成网格。
      改为**逐层单独估竖缝**——错缝的本质就是相邻层竖缝错开半块。

      **结果（`experiments/brick_running_bond.png`，每材质 3 样本）**：

      | 材质 | 横缝 | 各层竖缝 | 结果 |
      | --- | --- | --- | --- |
      | desert_stone_brick | [7,15] | **[[15],[7]]** | ✅ 真正的错缝，砖块清晰 |
      | stone_brick | [7,15] | **[[15],[7]]** | ✅ 同上 |
      | brick | [2,6,10,14] | **全空** | ❌ 一条竖缝未检出，成横条纹 |

      前两个检出的 `[[15],[7]]` 正是**相邻层错开半块**的标准砌法，
      **从数据自动学出来的**，不是手工写的。

      **`brick` 失败的原因暴露了这类先验的本质限制**：
      它是 4 层薄砖，而**不同作者放竖缝的位置不一样**。
      横缝位置在作者之间高度一致（所以能检出），
      **竖缝相位不一致，跨作者平均后互相抵消**。

      → **数据平均出来的先验，只能捕捉在作者之间一致的结构。**
      横向分层一致，竖缝相位常常不一致。
      要覆盖后者，需要的不是更好的检测器，而是
      **按单个作者/单个样本估相位**，或让相位成为可采样的隐变量。

## A3r 头条撤回与拆解：错的统计量 + 样本不足 + 不该由它裁决

### 三个独立的毛病

**一、取错了统计量。** `0.035 = 0.453 − 0.418` 是**两组均值之差**，
被写进标着"距真人"的列，再和基线 0.207 比出 6 倍。
均值之差让方向相反的误差互相抵消——一半材质偏平一半偏噪，
聚合后接近零而每个材质都错。A3o 原文同段就给了逐材质中位距离
0.145 → 0.066（2.2 倍），抄进 method.md 时取错了列。

**二、样本不足。** 4 样本/材质。这与 A3q 同源，见下。

**三、这个指标没资格裁决结构先验。** A3o 自己记过：
**"模型无种子"在该指标上是 0.402、距离 0.016，比有种子的 T=1.3 更"好"**。
一个把"完全没有结构"排第一的指标，用来证明结构先验有效是无效的。
当时写了"所以它不能单独作为判据"，但仍然把它当成了头条。

**不撤。** 理由不是"我做的所以留着"，而是这个指标依它自己的记录

## A4 功效：先算了再让人标

`analysis/annotate/power.py`，双尾精确二项检验、alpha=0.05。
在负责人花十几分钟标注**之前**算，而不是标完再解释。

| 真实胜率 | n=47（有种子层） | n=20（对照层） |
| --- | --- | --- |
| 55% | 9% | 6% |
| 60% | 25% | 13% |
| 65% | 51% | 25% |
| **70%** | **78%** | 42% |
| 75% | 94% | 62% |

- 要有 80% 功效，真实胜率需达 **71% 以上**。
- n=47 要观察到 **31/47（66%）** 才达到 p<0.05。

### 因此改了一条预注册判读规则

原规则写「~50% → 先验未转化为人的偏好，不值得继续扩」。
**这是过度断言**：n=47 下观察到 50% 与真实 58% 无法区分。
改为「~50% 只能排除 ~70% 以上的大效应」。

对照层 n≈20 在真实 60% 时功效只有 13%，
它是**合理性检查而非检验**，不能拿它的「无显著差异」当证据。

**A4 是探路不是终审**：它能可靠回答的只有"有没有大到 ~70% 的效应"。
真实效应若在 55–65%，本轮大概率测不出，必须扩到 A5。

**一、种子本身检出率 1.00。**（`seed_survives.py`）
七个启用错缝的材质无一例外。先验把缝放对了。

**二、但那个 1.00 是虚的**——种子图里未定格子填的是常数，
对比度人为满格。换成**匹配该材质边缘分布的随机噪声**后分化明显：

| 材质 | 周期 | 真人 | 种子+噪声 |
| --- | --- | --- | --- |
| `default_brick` | 8 | 0.47 | **0.08** |
| `tnt_blast` | 8 | 0.63 | **0.14** |
| `vessels_shelf` | 6 | 0.46 | 0.50 |
| `nc_woodwork_plank` | 4 | 0.42 | **0.81** |
| `wool_*` | 4 | 0.38–0.45 | **0.90+** |

周期 4 扛得住噪声，周期 8 扛不住。

**三、猜想"真人靠面内均匀让缝显出来"——formulate 错了。**
第一版量的是"面内方差 / 面间方差"，真人是 11.87。
但所有砖面本就是同一材质、均值天然接近，面间方差必然小，
**这个比值几乎必然大于 1，它根本不回答缝显不显**。
不是猜想被推翻，是问题问错了。记在这里以免再犯。

改量**缝列相对非缝列的对比度**（以列廓线标准差为单位）：

| | 真人 | 种子+噪声 |
| --- | --- | --- |
| `default_brick` | 1.27 | 0.90 |
| `tnt_blast` | 1.54 | 1.32 |
| `wool_blue` | 1.03 | **1.86** |

**缝不弱**，有些材质噪声版对比度还更高。

### 结论：是检测统计量脆弱

`_col_period` 在 lag 3–8 上取自相关**最大值**——赢者通吃。
周期 4 在 16 列里有 4 根缝，真峰稳赢；
周期 8 只有 2 根，噪声在别的 lag 上造出的伪峰就能夺冠。

所以 **A3q 用来证明改进的那个指标，恰在它被用的地方（周期 8 的砖）最不可靠**。

**对 A3q 的影响**：机制部分不受影响——周期跨作者一致 89%、
相位不一致 27%、相邻层差半周期 44 对里 27 对，这些是直接统计不经过检测器。
受影响的是"竖缝检出 0.08 → 0.15"这个**改进幅度**，
它建立在一个对周期 8 不可靠的量上，不能当作 A3q 有效的证据。

这是本项目第三次发现自己的**测量工具**比结论更可疑
（头条取错统计量、结构尺子第 3 条恒真、这次的赢者通吃）。


## A3t 试图修检测器，失败；而且暴露了对比基准本身不干净

A3s 查明旧检测器赢者通吃，明显的修法是：
**周期是先验给的，不需要 argmax**——改成在已知 lag 上做置换检验。
写了 `joint_detect.py`，验收判据先定死：新检测器必须把
"真人 vs 种子+噪声"分得**更开**。

结果相反：分离度中位从旧的 **+0.15 掉到 −0.38**。不采用。

### 为什么会更差

在**先验放缝的那个周期上**检验，等于在确认先验自己放的种子。
`wool_*` 上噪声版直接 1.00、真人只有 0.12——**这是循环论证**。
旧检测器因为要在 lag 3–8 上竞争，反倒没那么循环。

### 更要紧的推论：基准不干净

新检测器下真人的绝对值很低（`default_brick` 0.26、`tnt_blast` 0.03、
`vessels_shelf` 0.02）。真人瓦片在**先验估出的周期与相位**上本来就检不太出——
因为**相位跨作者本来就不一致**，这正是 A3l 最早发现的事。

所以"生成图竖缝检出率 vs 真人竖缝检出率"这个对比
**从一开始就不干净**：它拿一个真人自己都不共享的相位当基准。
A3q 的改进幅度在 A3s 已经撤掉，这里补上第二个理由。

**仍然成立的**：A3q 的机制发现（周期一致 89%、相位不一致 27%、
相邻层差半周期 44 对里 27 对）都是直接统计，不经过任何检测器。
错缝先验在 `bond_select.py` 里的逐材质选择也不受影响——
它比的是两种种子在**同一个**（有偏但一致的）量下的相对表现。

**方向**：竖缝这条线上，可靠的定量判据我没造出来。
剩下能裁决的是描述子尺子（前两条判据通过）和人工盲比。


## A3u 结构尺子：两条通过、一条不通过，按通过的范围用

`analysis/structure_grain/struct_metric.py`，判据在测之前写死。

| 判据 | 结果 |
| --- | --- |
| 1 真人留出最好 | ✅ 17.61 vs 有种子 47.34 |
| 2 无种子最差 | ✅ 62.30 vs 有种子 47.34 |
| 3 颗粒材质罚硬塞结构 | ❌ 56.60 vs 56.30，+0.5%，p=0.283 |

折半 ρ=+0.865、相对差 8.4%，稳定（量纲修好之后）。

**第 2 条是关键**：旧的全局平坦度指标把无种子模型排**第一**（A3r），
新尺子把它排**最后**。这正是造它的原因。

**第 3 条不通过的后果**：不能用它证明"先验在颗粒材质上正确地不作为"。
那条结论（method.md 边界表里的 ✅）目前只有"检不出周期所以种子为空"这个
构造性论证，没有独立的定量支撑。已在 method.md 标明使用范围。

### 过程上的两个自纠

- **折半门的阈值只在一个量纲下成立**：绝对差 0.02 是照平坦度（0–1）定的，
  套到量程 17–62 上把 7% 的相对差误判成不稳定。改成相对量并验了跨量纲一致。
- **第 3 条最初是恒真的**：颗粒材质检不出先验、种子为空，
  "有种子"和"无种子"在代码里是同一次计算，差必然 0.000。
  改成主动硬塞假先验之后它才可能不通过——然后它就不通过了。

### 还有一个流程教训

给脚本加瓦片存档的那次编辑**静默没生效**（`str.replace` 不匹配时不报错），
我只验了语法就当它成功，直到发现产物不存在。

## A3v 缝的档位与"这行到底是不是缝"

从一个拍脑袋的常数查起：`learn_prior` 把缝色取成整幅图索引的 **15 百分位**。
但缝在哪些行是检出来的，可以直接量真人在那些位置用什么档位
（`analysis/structure_grain/seam_level.py`，66 个有横缝的材质）：

| | 中位 |
| --- | --- |
| 现行常数（15 百分位） | 0.133 |
| 缝行实测档位 | **0.400** |
| 真人的缝比面暗 | 0.146 |
| 常数造成的落差 | 约 0.40（近三倍） |

**56/66 个材质我们把缝画得比真人更暗**——砖缝被画成了近乎黑线。

### 但改成实测档位，画面基本没变

`experiments/seam_vs.png`：`stone_brick` / `desert_stone_brick` 网格略清晰，
`wood` / `bookshelf` 几乎不变，**`nc_woodwork_plank` 明显变差**（0.13→0.43，缝消失）。
"更接近真人的档位"没有转化成"更好的图"。又一次指标动、画廊几乎不动。

### 真正有效的是它顺带暴露的问题

`nc_woodwork_plank` 变差的原因是实测缝档位 0.43、面档位也是 0.43——
**那里根本没有暗缝**，行检测抓到的是别的东西。既然没有缝就不该画。

加一道门：**缝必须比面暗 ≥0.08 才播种**。66 个材质拦下 13 个，
包括 `mcl_core_gold_ore`（缝比面暗 **0.000**）、`beds_bed_top2`（0.019）。

图上是明确改进：

- **`default_diamond_block`**：原本一片蓝加几个白点、毫无结构；
  拦下假缝后**边框结构显出来了**，接近真人的框形。
- **`beds_bed_top2`**：原本红底散点；拦下后出现真人那样的白色区块。
- 缝够暗的材质（brick / stone_brick / wood）基本不变。
- `nc_woodwork_plank` 模棱两可甚至偏负——板条线也一起没了。

机理：假缝把 16 行里的 4 行钉死成同一档位，
等于给模型一个**错的骨架**，把本该出现的结构挤掉。
先验的害处不在"少做"，在"做错"。

### 门的判据换了三次，前两次都是错的

**第一版：幅度 ≥0.08。** 编的。66 个材质的幅度分布单峰连续，
下半段最大间隙仅 0.019，**没有自然分界**，任何幅度阈值都没有数据支撑。

**第二版：跨作者方向一致率 ≥80%**（`learn_border` 的既有约定）。
**不适用**：实测把 `default_brick`(68%) 和
`default_obsidian_brick`(79%, 幅度 +0.433) 一起拦下。
原因是**相位**——检出的缝行是跨作者平均位置，
个别作者的缝错开一两行就落在砖面上。
边的位置没有相位歧义，缝行有，所以边框的约定不能照搬。

**第三版（采用）：置换检验 + 一个调色板档位的下限。**

- 置换检验：检出的这些行，是不是比**随机选同样多的行**显著更暗（p ≤ 0.05）。
  不受相位影响，也不需要编幅度阈值。
  真砖真木全过（brick p=0.00 幅度 +0.265、stone_brick p=0.01 +0.467、
  wood p=0.00 +0.450），假缝全拦（`mcl_core_gold_ore` p=0.96 幅度 +0.000、
  `farming_straw` 幅度 **−0.017**，缝比面还亮）。
- 但**显著不等于够大**：`default_diamond_block` p=0.04 而幅度只有 0.033，
  连 13 色调色板的半档都不到——**画不出来的缝不该画**。
  所以再加一条：幅度 ≥ 一个调色板档位。这不是拍脑袋，
  是"低于一档在离散调色板里根本无法表达"。

### 图上验收（`experiments/seam_vs.png`，每种 3 样本）

| 材质 | 结果 |
| --- | --- |
| `diamond_block` | 从"一片蓝加几个白点"到**显出边框结构** |
| `beds_bed_top2` | 从红底散点到出现真人那样的白色区块 |
| `mcl_core_gold_ore` | 矿点分布出来了 |
| `nc_woodwork_plank` | 设门版更有质感，不设门版偏平 |
| `acacia_wood` | 被拦下，但**板条线仍然在**——模型自己画得出来 |
| brick / stone_brick / wood | 缝真实，不受影响 |

**没有回归。** `acacia_wood` 那一格顺带说明：先验不是处处必需，
模型在木板上本来就能自己产生横向条纹。


## A3w 尺子验收之后的连带清算：哪些结论的支撑失效了

`struct_metric.py` 三条判据全过之后，回头看：
**此前用旧指标（全局平坦度 `frac_zero`）验过的结论，支撑全部失效**，
因为 A3r 证明该指标把"完全没有结构"排第一。

| 结论 | 原支撑 | 现状 |
| --- | --- | --- |
| 头条 6× | 组均值之差 + 4 样本 | 已撤回（A3r） |
| A3q 竖缝改进 0.08→0.15 | 赢者通吃的检测器 | 已撤回（A3s / A3t） |
| **A3p 分边边框** | **新覆盖 21 个材质 0.1445→0.0703，p=0.00035** | **⚠ 该数字用的正是被否掉的 `frac_zero`** |
| A3o 温度 1.3 | 全局色数与相邻同色比例 | ⚠ 同类问题，未复查 |
| A3v 缝的门 | 只有画廊 | 待新尺子评估（进行中） |

**A3p 仍然保留**，但理由改成两条不依赖该指标的：

1. 检测本身是直接统计——`carts_cart_side` 上边 +1.31/一致率 88%、
   下边 −1.37/94%，整圈因方向相反抵消到 +0.01/50%。
   这是"整圈检测有盲点"的证明，与生成质量无关。
2. 并集而非替代也是直接观察——`tin_block` 整圈过关但分边只有 bottom 达标。

**但"加了边框先验让生成更接近真人"这个结论，目前没有有效证据。**
排进队列用新尺子重验（开/关 `learn_edges` 各一次）。

A3o 的温度选择同理：色数与相邻同色比例都是全局像素统计，
不能区分"面内均匀面间不同"与"到处都花"。也需要复查。

**教训**：换掉一把尺子，要连带清算所有用它量过的结论，
而不是只改那一处记录。


## A3x 面被填平了，不是被填花了——A3o 的温度只在全局上修好了

A3w 把 A3o 的温度选择列入待复查：色数与相邻同色比例都是**全局**统计，
区分不了"面内均匀面间不同"与"到处都花"。

这次问对了问题——**同一个量在两个来源上比**
（A3s 那次比"面内方差/面间方差"是两个不同量的比值，必然 >1，问错了）：

| 57 个有结构材质 | 面内相邻同色 | 面内标准差 |
| --- | --- | --- |
| 真人 | 0.154 | 2.496 |
| **先验+填充** | **0.314** | 3.048 |
| 无种子模型 | 0.142 | 3.787 |

真人 vs 先验+填充：相邻同色 **p=6.0e-06**；标准差 p=0.147（不显著）。

### 结论与我的猜想相反

猜的是"填充太花把 1 像素的缝淹掉"。实测**恰好相反：面被填得太平**，
面内相邻同色是真人的**两倍**。
而**无种子模型和真人几乎一样**（0.142 vs 0.154）——
所以是**种子**把填充拖平的。

这正是 A3o 发现并试图用 T=1.3 修的效应。全局上看着修好了
（A3o：面内同色 0.232 vs 真人 0.209），
**但在面内看根本没修好**——全局统计里缝行自身的变化掩盖了面内的过度平坦。

### 对"砖不像砖"的解释换了方向

不是缝被噪声淹没，是**整块砖面被填成一坨近乎同色**，
所以看上去是色块而不是有质感的砖。

**下一步**：用面内相邻同色（对齐真人 0.154）重扫温度，
同时用结构尺子确认结构不被破坏（A3o 记录 T≥1.6 开始破坏结构，
但那也是用旧指标判的，一并复查）。
