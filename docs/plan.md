## 当前判断

前提验证的结论（`premise.md`）：「低分辨率纹理是重新设计」**目前证据不支持**。
「降采样 + 量化」是很强的基线。但那三个特征只测颜色和边缘，
没测母题结构，所以还不能说被证伪。

SD-πXL 的结论（`related-work.md`）不依赖上面这条，仍然成立：
**它在架构上没有区域约束能力**。这是目前最硬的一块证据。

## 步骤

- [ ] **S1 结构特征复测**
      现有三个特征（颜色数/平坦度/边缘锐度）只看局部像素统计。
      加一组**结构**特征再测一次 A vs C：
      - 二维自相关的主周期（木板有几条？砖有几行？）
      - 连通同色块的数量与尺寸分布
      - 行/列方向的游程长度分布
      问题：真人在 16px 下画的母题重复次数，是否显著少于降采样保留的？
      产出：更新 `premise.md` 的结论；若结构特征能干净分开（AUC > 0.75），
      则立论**部分成立**，卖点可以改成"母题结构"而非"整体风格"。

- [ ] **S2 把「降采样+量化」做成正式基线**
      不管 S1 结论如何，这条基线都必须能跑、能量化。
      针对本项目真正的任务（纯色图 + 材质名 → 像素纹理）实现：
      高分辨率纹理 → 面积降采样 → 量化到给定调色板 → 裁进给定区域。
      产出：`baselines/downsample_quantize/`，以及它在轮廓 IoU 上的得分
      （SD-πXL 最好 0.86，这个基线应当接近 1.00，因为区域是硬裁的）。

- [ ] **S3 重写项目定位**
      根据 S1/S2 结果重写 `README.md` 的任务陈述与卖点。
      若前提确实不成立，卖点转向「在给定区域和给定调色板内可控生成」，
      并把 SD-πXL 的 IoU 证据作为主 motivation。
