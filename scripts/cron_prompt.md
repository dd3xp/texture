## 做法上的规矩（服务于目标，不许喧宾夺主）

- **结果不好就如实写不好，然后改架构再训。** 不许转去审计或写论文来填满时间。
- **只有挡住训练/评测的 bug 才修**；其他审计、复核、措辞修订一律不做。
- **指标用领域通用的**（见 `docs/arch_plan.md` 调研部分），不许为了让自己赢而自造指标。

  训练只用 `split=train`，调参只用 `split=val`。**绝不拿测试集调参。**
- 数据许可：ContentDB 许可干净的包，已排除 Minecraft 系（见 `docs/dataset.md`）。

- 需要新的 Python 包：**不许往共享 conda 环境装**。优先在仓库里自己实现；

## 环境坑（会静默咬人）

- **Bash 工具把 `\\` 折叠成 `\`**：Python 补丁里的字符串匹配会悄悄失配，
  `replace` 返回原串而脚本正常退出；写进 LaTeX 会把 `\ref` 变成回车 + `ef{...}`，
  **pdflatex 不报错**。对策：按行号切片替换、`replace` 后必加 `assert count==1`、
  含反斜杠的文件用 Write 工具。
- **tmux 不继承 ssh 的环境变量**（服务器 tmux 很久以前就起了）：
  变量要写进 `new-session` 的命令串里。
- **`sync_to_emnlp.sh` 不带被 gitignore 的文件**：新建的输入表要么加豁免、要么 `scp`。
- **离线加载 LoRA 必须给 `weight_name`**，否则静默退回基础模型。
