## 做实验的规矩（本项目所有主张靠这个立住）

- **判据必须写下来并 commit，然后才跑。** 事后改判据 = 挑好看的结果。
- **操作检验要量下游真正会被评判的那个量**，不能量中间对象
  （已因此作废三轮：调色板跨度、`frac=1.0` 的伪触发、B11）。
- **任何判读都要跟着数据分支**，不要无条件打印结论——本项目已犯四次。
- **VLM 判官压缩效应**：可支持「有大效应」（作下界）、可证伪零假设，
  **不能确认零假设**。负结果只能说「没测到大效应」。
- 目视判断不是结论，标 ⚠ 并注明待盲比。
- 改完脚本跑 `python analysis/check_names.py`（抓潜伏 NameError，本地跑不了的脚本尤其要）。

## 环境坑（会静默咬人）

- **Bash 工具把 `\\` 折叠成 `\`**：Python 补丁里的字符串匹配会悄悄失配，
  `replace` 返回原串而脚本正常退出；写进 LaTeX 会把 `\ref` 变成回车 + `ef{...}`，
  **pdflatex 不报错**。对策：按行号切片替换、`replace` 后必加 `assert count==1`、
  含反斜杠的文件用 Write 工具。
- **tmux 不继承 ssh 的环境变量**（服务器 tmux 很久以前就起了）：
  变量要写进 `new-session` 的命令串里。
- **`sync_to_emnlp.sh` 不带被 gitignore 的文件**：新建的输入表要么加豁免、要么 `scp`。
- **离线加载 LoRA 必须给 `weight_name`**，否则静默退回基础模型。
